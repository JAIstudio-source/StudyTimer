# Privacy Policy for StudyTimer

> Last Updated: September 3, 2026 &bull; Effective Date: August 14, 2026

At **StudyTimer**, we are committed to safeguarding your privacy. This policy outlines what data we collect, how it is stored, and your data rights.

## 1. Information Collected
- **Account Identifiers:** Google profile display name, email address, avatar when opting into cloud sync.
- **Study Records:** Timestamps, Pomodoro intervals, custom subject names, color tags, and daily streak counts.
- **Crash Telemetry:** Anonymized installation IDs and system logs.

## 2. Storage & Security
- **Offline-First:** All records are stored locally on device using encrypted SQLite/Room.
- **Encrypted Cloud Sync (Optional):** Supabase PostgreSQL database secured with Row Level Security (RLS) over HTTPS (TLS 1.3).

## 3. Data Deletion
Permanent account and cloud deletion can be executed in-app under *Settings > Delete Account* or via https://get-studytimer.vercel.app/delete-account.html.
