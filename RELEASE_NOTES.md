# StudyTimer 2.5.5 (versionCode 16)

What's New in Version 2.5.5 🚀
- 3D Look UI & Volumetric Accents: Modern tactile 3D capsule buttons, volumetric depth icons, and customized Focus/Break color accents.
- 1-Hour Pomodoro Focus Default: Pre-configured 1-hour Pomodoro countdown with seamless active timer tracking.
- Automatic Daily Goal Reset: Goals in your planner auto-reset every midnight for a fresh daily streak & checklist.
- High-Resolution Notification Logo: Custom app logo badge displayed on status bar and notification tray.
- Spacious CSV Log Export: Completely redesigned CSV export with formatted summary tables for Excel & Google Sheets.
- Interactive App Guide: Revisit feature guides and tips anytime from Settings -> About -> How to Use / App Guide.
- Smooth Performance & Stability: Enhanced theme preservation for app updates, responsive touch animations, and zero-bug stability.

## Compatibility
- Android 9 (API 28) through Android 16 (API 36)
- Signed with official release key.

## Installation
Install `StudyTimer-release.apk` (v2.5.5). Updating preserves all your study logs, streaks, and settings.
