# StudyTimer Automation & Graphics Scripts

This directory contains standalone Node.js and image generation scripts for marketing assets and store graphics:

- `generate_feature_graphic.mjs`: Generates high-resolution Google Play Store feature graphics (1024x500).
- `generate_showcase.mjs`: Generates promotional multi-screen showcase layouts.
- `generate_plain_screenshots.mjs`: Composes raw device screenshots into captioned presentation slides.
- `compose.mjs` / `compose_v2.mjs`: Advanced canvas compositing and typography rendering.

### Usage
Run from root:
```bash
npm run generate:feature
npm run generate:showcase
npm run generate:screenshots
```
