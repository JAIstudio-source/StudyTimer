## Key Features

### 1. Active Pomodoro Focus Engine
- Customizable work intervals (25m / 50m / custom)
- Short (5m) and long (15m) rest blocks
- Ambient audio soundscapes and vibration cues
- Real-time visual stamina countdown dial

### 2. Custom Course Subjects & Target Goals
- Unlimited custom subjects (e.g. Physics, Coding, Mathematics, Organic Chemistry)
- Hex color badges and tags
- Daily and weekly target hour goals with visual progress bars

### 3. Visual Monthly Streak Calendars
- Day-by-day habit chains
- Monthly study consistency heatmaps
- Longest and current streak tracking

### 4. Deep Time Analytics & Heatmaps
- Hourly breakdown and peak study time insights
- Subject percentage distributions
- 7-day, 30-day, and all-time trend charts

### 5. 100% Offline-First Architecture
- Built on local encrypted SQLite / Room database
- Works without internet connectivity or cellular data
- Optional encrypted Google Cloud Sync via Supabase PostgreSQL

### 6. Zero Ads & 100% Free
- No banner ads, no popups, no video interstitials
- Zero subscription tiers or locked features
