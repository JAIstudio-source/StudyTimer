# StudyTimer 2.5.1 (versionCode 15)

What's New in Version 2.5.1 🚀
- Floating Heads-Up Banner Notifications: High-priority pop-up cards for class starting, class ended, goal completion, and reminders.
- Direct Notification Panel Actions: Switch between study and break directly from the notification shade without opening the app.
- Pomodoro Focus Continuity: Resuming focus after a break continues from where you left off.
- Dedicated Lecture & Stopwatch Dual Mode: Clean manual stopwatch mode without false end popups, plus smart class switch confirmation.
- Secure Cloud Sync: Sign in to safely back up your study data and restore it anytime, anywhere.
- Habit & Lecture Planner: Dedicated planners built specifically to organize your daily routines and study schedule.
- Performance Boosts & UI Optimization: Faster rendering, lower memory overhead, and enhanced stability.

## Compatibility
- Android 9 (API 28) through Android 16 (API 36)
- Signed with official release key.

## Installation
Install `StudyTimer-release.apk` (v2.5.1). Updating preserves all your study logs, streaks, and settings.
