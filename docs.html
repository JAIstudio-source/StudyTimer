2. Model Context Protocol (MCP) Server

StudyTimer provides a native first-party MCP server conforming to the 2024-11-05 specification. AI agents (such as Claude Desktop, ChatGPT, Cursor, and Ora) can connect natively via Streamable HTTP transport: 

{
  "mcpServers": {
    "studytimer": {
      "url": "https://get-studytimer.vercel.app/api/mcp",
      "transport": "http"
    }
  }
}

Available MCP Tools:

  • get_app_info: Returns app version, capabilities, and system specifications.
  • get_download_link: Generates verified APK download links and checksums.
  • calculate_pomodoro_schedule: Calculates optimal study blocks, short breaks, and long breaks based on target study duration.
  • validate_study_session: Validates study log parameters and intervals.
  • submit_feedback: Submits bug reports and feedback directly to the development team.

3. Feedback & Telemetry API

Endpoint: POST /api/feedback

Accepts user feedback, bug reports, and diagnostic submissions with sliding-window rate limiting.

POST /api/feedback HTTP/1.1
Host: get-studytimer.vercel.app
Content-Type: application/json

{
  "email": "student@example.com",
  "category": "feature_request",
  "message": "Add white noise ambient audio during focus intervals.",
  "app_version": "3.0.0",
  "device_info": "Pixel 8 Pro - Android 14"
}

4. Database & Data Sync Architecture

StudyTimer operates an offline-first Room database schema synchronized to Supabase PostgreSQL:

  • subjects: Subject UUIDs, title, color_hex, weekly_target_minutes, created_at.
  • study_sessions: Session UUIDs, subject_id, start_time, duration_seconds, session_type (pomodoro/stopwatch), notes.
  • daily_streaks: Date, total_seconds, target_met_flag, updated_at.
