# StudyTimer 2.5.6 (versionCode 17)

What's New in Version 2.5.6 🚀
- **Fixed Known Bugs**: Fixed dashboard metric rendering issues, enhanced crash stability, and optimized background process handling.
- **Added Privacy**: Introduced comprehensive privacy policy transparency, instant 1st launch telemetry reporting, and enhanced user data deletion controls.
- **3D Look UI & Volumetric Accents**: Modern tactile 3D capsule buttons, volumetric depth icons, and customized Focus/Break color accents.
- **Automatic Daily Goal Reset**: Goals in your planner auto-reset every midnight for a fresh daily streak & checklist.
- **Interactive App Guide**: Revisit feature guides and tips anytime from Settings -> About -> How to Use / App Guide.

## Compatibility
- Android 9 (API 28) through Android 16 (API 36)
- Signed with official release key.

## Installation
Install `StudyTimer-release.apk` (v2.5.6). Updating preserves all your study logs, streaks, and settings.
